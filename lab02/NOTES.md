Различие GIT и github:
Git -- инструмент контроля версий. Позволяет коммитить изменения, откатывать ветки, просматривать изменения, но ЛОКАЛЬНО. 
GitHub -- самый популярный портал для пуша изменений (делается через git push), для отправки изменений на сервер (для работы в команде/распространении продукта и т. п).
GitHub не обязателен, может быть заменен другим порталом
